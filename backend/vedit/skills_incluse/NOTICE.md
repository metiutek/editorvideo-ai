# Notice: built-in animation and editing skills

The skills in this folder are **adapted, condensed and rewritten** for vedit from the open-source
skills below. They are not verbatim copies: tool names, numbers and examples were reworked to
match vedit's own tools (`add_block`, `add_html`, `set_transform`, `make_captions`...), and
parts specific to other engines (Remotion, After Effects, Node render scripts) were left out.
Each skill names its sources in its `source:` line.

| Skill here | Adapted from | Licence |
|---|---|---|
| `motion-craft` | HyperFrames `skills/hyperframes` (motion, captions): github.com/heygen-com/hyperframes; iart.ai `animation-principles`: github.com/iart-ai/motion-design-skills | Apache-2.0; MIT |
| `kinetic-typography` | iart.ai `kinetic-typography`: github.com/iart-ai/kinetic-typography-skills | MIT |
| `data-animation` | iart.ai `chart-animation`, `animated-infographic`: github.com/iart-ai/data-animation-skills | MIT |
| `short-form-video` | iart.ai `short-form-video`: github.com/iart-ai/tiktok-video-skills; HyperFrames captions reference; video-use subtitle styles | MIT; Apache-2.0; MIT |
| `lower-thirds` | iart.ai `lower-thirds`: github.com/iart-ai/lower-thirds-skills | MIT |
| `explainer-styles` | iart.ai `explainer-video`, `whiteboard-animation`: github.com/iart-ai/explainer-video-skills | MIT |
| `product-launch` | iart.ai `launch-video`: github.com/iart-ai/ad-video-skills; principles of video-shotcraft: github.com/Vincentwei1021/video-shotcraft | MIT; Apache-2.0 |
| `talking-head-edit` | browser-use `video-use`: github.com/browser-use/video-use | MIT |
